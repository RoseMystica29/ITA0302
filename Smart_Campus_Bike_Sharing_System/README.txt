SMART CAMPUS BIKE SHARING MANAGEMENT SYSTEM

How to run:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html.
4. Right-click and select 'Open with Live Server'.

Features:
- Professional responsive admin dashboard
- User registration and management
- Bicycle fleet management
- Start and end ride sessions
- Distance and duration tracking
- Automatic fare calculation (₹5/km + ₹1/minute)
- Revenue and utilization reports
- localStorage data persistence
- Print report option
